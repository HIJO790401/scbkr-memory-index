# scbkr-memory-index

Public-facing frontend project for **SCBKR Memory Index**.

## Location

- Frontend entry is in [`main-root/index.html`](main-root/index.html).
- Styles are in [`main-root/styles.css`](main-root/styles.css).

## Deploy

This project is static and GitHub Pages friendly.

1. Push repository to GitHub.
2. Enable Pages on the default branch.
3. Set Pages root to `/main-root` (or publish with GitHub Actions).
