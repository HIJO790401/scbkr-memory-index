SCBKR Core Schema

  • S · Subject主體 / 事件核心對象
  • C · Cause原因 / 背景脈絡
  • B · Boundary邊界 / 限制條件
  • K · Key Evidence關鍵證據 / 來源鏈
  • R · Responsibility責任歸屬 / 追溯節點

Open indexing layer only · 僅開放索引層，不包含封閉治理判斷核心

About SCBKR / 關於 SCBKR

What it is / 是什麼

SCBKR is a structured memory indexing framework: Subject, Cause, Boundary, Key Evidence, Responsibility. It standardizes how memory units are organized and routed over long AI sessions.

SCBKR 是一種結構化記憶索引框架，將長期 AI 記憶拆成 Subject、Cause、Boundary、Key Evidence、Responsibility 五欄位，讓記憶單元具備一致性與可追溯性。

Why not RAG-only / 為何不只做 RAG

Traditional RAG retrieval focuses on matching chunks. SCBKR focuses on indexing logic, replayability, auditability, and routing behavior so memory can remain coherent across time.

本專案重點是「索引結構」，不是封閉治理或判斷引擎；它提供可重播、可稽核、可路由的公開層，協助你對接自己的模型。

Quick Deployment Guide / 快速部署教學

Step 1 · Download Repo

Click Download Repository ZIP, unzip locally, and locate the main-root folder.

按下下載後解壓，找到 main-root 目錄，這就是你的靜態前端入口。

Step 2 · Run Locally

cd main-root
python3 -m http.server 8080

Open http://localhost:8080 to preview. 在本機即可立即預覽。

Step 3 · Deploy to GitHub Pages

Push repo to GitHub → Settings → Pages → select branch/folder. Set folder to main-root for this frontend.

如果你不熟部署，照這 3 步做就可以上線靜態前端版。
