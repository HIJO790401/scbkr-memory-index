About SCBKR / 關於 SCBKR

What it is / 是什麼

SCBKR is a structured memory indexing framework: Subject, Cause, Boundary, Key Evidence, Responsibility. It standardizes how memory units are organized and routed over long AI sessions.

SCBKR 是一種結構化記憶索引框架，將長期 AI 記憶拆成 Subject、Cause、Boundary、Key Evidence、Responsibility 五欄位，讓記憶單元具備一致性與可追溯性。

Why not RAG-only / 為何不只做 RAG

Traditional RAG retrieval focuses on matching chunks. SCBKR focuses on indexing logic, replayability, auditability, and routing behavior so memory can remain coherent across time.

本專案重點是「索引結構」，不是封閉治理或判斷引擎；它提供可重播、可稽核、可路由的公開層，協助你對接自己的模型。

Quick Usage Guide / 快速使用指南

Step 1 · 找到使用資料夾

下載 Repo ZIP 解壓後，真正要使用記憶索引的目錄是 main-root/starter-package/memory-index/。

This is the working folder for memory indexing, not the frontend page folder.

Step 2 · 放入你的記憶資料

把你的檔案放進以下三個子目錄：

memory-index/json/
memory-index/drive-import/
memory-index/local-private/

這樣可用同一套 SCBKR 結構管理不同來源記憶，降低遺忘與漂移。

Step 3 · 產生索引後接自己的模型

cd main-root/starter-package
python3 tools/auto_index.py   --source ./memory-index   --output ./memory-index/index.scbkr.generated.json

接著用你自己的模型讀取這份索引做 recall / route / replay。 This is how you keep memory structured and less forgetful over sessions.
